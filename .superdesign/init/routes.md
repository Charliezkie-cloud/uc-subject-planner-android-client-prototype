# Routes

| Route | Entry file | Layout | Summary |
| --- | --- | --- | --- |
| `/plan` | `app/(tabs)/plan.tsx` | Tabs | Term-by-term plan and eligibility |
| `/subjects` | `app/(tabs)/subjects.tsx` | Tabs | Completed-subject grades |
| `/courses` | `app/(tabs)/courses.tsx` | Tabs | Curriculum selection and course browser |
| `/settings` | `app/(tabs)/settings.tsx` | Tabs | App actions and information |

`app/_layout.tsx` defines the root stack and `app/(tabs)/_layout.tsx` defines the four-tab navigator.
